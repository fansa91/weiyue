# 微阅（只读客户端）

非官方第三方 Flutter 客户端，**访客态只读**：浏览热门/分类流、视频、热搜、搜索、用户主页与视频播放，不含发布/评论/点赞等写操作。

## 功能（v1）

- **首页**：热门 + 58 个兴趣分类的动态流，下拉刷新 + 游标分页；正文富文本高亮（话题/@/链接）、图片宫格、视频封面、转发内嵌卡、长文「全文」。
- **视频页**：推荐/短剧/电影/电视剧/综艺/游戏分类中带视频的动态大卡列表。
- **播放器**：media_kit 播放多档直链，默认 ≤720p 最高档，可切换画质；下方相关视频推荐。
- **发现**：热搜榜（名次/爆·热·新标/热度）+ 六大分类热词榜；点击词条直达搜索。
- **搜索**：移动端综合搜索，一次拉取后本地分段（综合/用户/动态）。
- **详情**：完整动态 + 长文自动补全 + 评论区（**访客仅热评**，带横幅说明）+ 点赞列表 + 相关视频；转发列表访客不可见（占位说明）。
- **用户主页**：封面/头像/认证/简介/三计数 + 资料弹窗；动态、视频（含合集横列，详情页为后续版本占位）、相册三页签。
- **我的**：双栈访客身份状态与手动刷新、设置、外观（沿用模板 M3 主题系统：动态取色/种子色/纯黑）、关于。

## 接口来源

全部接口来自内部网页端逆向整理文档（唯一依据）。双栈：桌面端站点接口 + 移动端站点容器体系。访问前经访客系统换取访客 Cookie，业务请求遇登录重定向 / 访客失效标记 / 特定 403 自动重换访客重试一次。

## 访客限制（服务端硬限，非客户端缺陷）

- **评论**：只下发 1 条热评（总数照常上报），详情页以横幅明示。
- **转发列表**：完全拦截，详情页做占位说明。
- **关注流 / 我的时间线**：访客 403 不可用——本应用不提供关注流。
- 用户时间线、全文搜索、点赞列表访客可读（走移动端栈），故主页/搜索/点赞可用。
- 图片/视频 URL 带时效签名，过期需重新拉取详情刷新。

## 登录与写操作

v1 不做。v2 计划：WebView 登录后收割登录态 Cookie 复用同一数据层；账号密码直登未用真实账号验证过，不在计划内。

## 构建

沿用模板 CI（`.github/workflows/release.yml`，Flutter 3.47.7）：推 `v*` 标签触发多端发布——Android APK（分架构，自签）、iOS IPA（未签名）、macOS DMG、Linux deb/rpm/AppImage/pacman、Windows zip。Android job 在 Analyze 后跑 `flutter test`。

本地：

```bash
flutter pub get
flutter analyze
flutter test
flutter run            # 或 flutter build apk / build macos 等
```

## 测试

```
test/widgets/   StatusCard 五种形态与图片宫格布局
test/screens/   首页/详情（热评横幅）/发现/主页/我的/主壳四栏切换
test/fixtures/  自逆向样本裁剪的真实返回
```
